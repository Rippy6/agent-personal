# 完全自律AIエージェント

**指示を待たず、自分で考え、判断し、行動する「もう1人の人間」**

## これは何？

普通のAIツールは「命令されたことをやる」だけ。
このエージェントは違います。

- 何も指示しなくても、自分で環境を観察して「何が必要か」を考える
- ゴールを1つ渡すだけで、自動でタスクに分解して実行する
- 過去の失敗を覚えていて、同じミスを繰り返さない
- やることがなくなっても、好奇心で探索を続ける

## はじめかた

### 1. セットアップ

```bash
python setup.py
```

対話形式のウィザードが、設定をステップバイステップで案内します。

### 2. 動かす

3つのモードがあります:

#### 🎯 自律モード — ゴールだけ渡して、あとはおまかせ

```bash
python main.py -g "このリポジトリを分析して報告して"
```

エージェントが自分で計画を立て、必要なツールを選び、実行します。

#### 💬 対話モード — チャットしながら一緒に作業

```bash
python main.py -i
```

会話しながら指示を出せます。「ゴール」「記憶」と入力すると状態が見れます。

#### 🔍 探索モード — 何も指示しない

```bash
python main.py
```

何も言わなくても、環境を自分で見回って気づいたことを報告します。

### オプション

| オプション | 説明 | 例 |
|---|---|---|
| `-g "..."` | ゴールを指定 | `-g "ファイルを整理して"` |
| `-i` | 対話モード | |
| `-v` | 詳細表示（思考の全過程が見える） | |
| `-n 数字` | 最大ループ回数 | `-n 50` |
| `-d 秒数` | ループ間の待ち時間 | `-d 0.5` |
| `--dry-run` | コマンドを実行せず表示だけ | |

## どうやって動いているの？

エージェントは5つのステップを繰り返し実行します:

```
🔍 観察  →  💭 思考  →  📋 計画  →  ⚡ 実行  →  📝 振り返り
                          ↑                            │
                          └────── 次のサイクル ──────────┘
```

1. **観察**: 今どんな状態か（ファイル、ゴール、前回の結果）を確認
2. **思考**: 観察をもとに「次に何をすべきか」を判断
3. **計画**: やるべきことをステップに分解
4. **実行**: ツール（ファイル操作、コマンド実行など）を使って行動
5. **振り返り**: うまくいったか評価し、学びを記憶に保存

### 使えるツール

| ツール | できること |
|---|---|
| `file_read` | ファイルの中身を読む |
| `file_write` | ファイルを作成・上書き |
| `file_list` | フォルダの中身を一覧表示 |
| `shell` | シェルコマンドを実行（安全チェック付き） |
| `web_fetch` | Webページの内容を取得 |
| `note` | メモを保存・検索（長期記憶に残る） |

### 記憶のしくみ

- **短期記憶**: 今のセッション中だけ覚えている（最大50件）
- **長期記憶**: `data/memory.json` に保存。次回起動時にも覚えている

### 思考エンジン（Brain）

| モード | 特徴 |
|---|---|
| デモモード | APIキー不要。ルールベースで動く。まずはこれで試す |
| Claude API | Anthropicの AIを使った本格モード。賢く柔軟に判断できる |

Claude APIを使うには:
```bash
export ANTHROPIC_API_KEY=your-key-here
python main.py -g "プロジェクトを改善して"
```

## プロジェクト構成

```
agent-personal/
├── main.py           ← 起動するファイル
├── setup.py          ← セットアップウィザード
├── agent/
│   ├── core.py       ← エージェントの心臓部（5フェーズループ）
│   ├── goal.py       ← ゴール管理
│   ├── brain/        ← 思考エンジン
│   │   ├── mock.py   ← デモ用（APIキー不要）
│   │   └── claude.py ← Claude API接続
│   ├── memory/       ← 記憶システム
│   │   ├── short_term.py  ← 短期記憶
│   │   └── long_term.py   ← 長期記憶
│   └── tools/        ← ツール群
│       ├── file_ops.py    ← ファイル操作
│       ├── shell.py       ← コマンド実行
│       ├── web.py         ← Web取得
│       └── notes.py       ← メモ
└── data/             ← 実行時に自動作成
    ├── config.json   ← 設定（setup.pyで生成）
    ├── memory.json   ← 長期記憶
    └── goals.json    ← ゴールの状態
```

## 動作例

```
🤖 完全自律AIエージェント v0.1.0

🎯 [ゴール] 新しいゴール: カレントディレクトリのファイル一覧を確認して
🔧 [システム] エージェント起動
🔍 [観察] 環境スキャン (イテレーション 1)
💭 [思考] 「.」はディレクトリだ。中身を見てみよう。
📋 [計画] .の一覧を取得 → 気になるファイルを読む
⚡ [実行] file_list: directory="."
📝 [振り返り] 「file_list」は成功した。ゴールを完了。
🔍 [観察] 環境スキャン (イテレーション 2)
💭 [思考] 特に指示はないが、まだ「agent」を見ていない。探索してみよう。
📋 [計画] agentの内容を確認 → 興味深いものがあれば深掘り
⚡ [実行] file_list: directory="agent"
📝 [振り返り] 構造を把握した。
```

ゴール完了後も自分で探索を続けているのがわかります。
